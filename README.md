# 資訊科技知識 刷題復習系統

全澳中學生資訊科技知識問答比賽（高中組）· 刷題復習系統

一個**免安裝、免伺服器**的刷題系統。雙擊 `index.html` 即可使用，所有資料儲存在瀏覽器本機。

---

## 快速開始

**方式一：直接開啟（最簡單）**
雙擊 `index.html`，用 Chrome / Edge / Firefox 開啟即可。

**方式二：本地伺服器（推薦，資料儲存更穩定）**

```bash
cd D:\ICK-Competition
python -m http.server 8123
```

然後瀏覽器開啟 <http://localhost:8123>

## 功能

### 使用者登入

開啟後需先登入才能使用。內建 **10 個帳號**（`stu01` ~ `stu10`），詳見 [`帳號清單.md`](帳號清單.md)。

- 帳號、密碼由管理員發放；學生忘記密碼可請管理員在後台重設
- 登入狀態會記住，重新整理不用重新輸入；右上角可登出
- **每個帳號的練習進度各自獨立**（正確率、錯題本、收藏、練習歷史都分開）
- 未登入時，首頁／學習統計／錯題本等項目不會顯示

### 普通使用者（學生）

| 功能 | 說明 |
|---|---|
| 分類練習 | 9 大分類可任意勾選組合，未勾選時視為全部 |
| 順序練習 | 每次開始重新抽題，抽中後依題號順序作答 |
| 隨機練習 | 隨機抽題，打亂順序鞏固記憶 |
| 錯題重做 | 只練曾答錯的題目，答對後自動移出錯題本 |
| 模擬考試 | 限時作答（每題 45 秒），交卷後才顯示答案與解析 |
| **每次重新抽題** | **預設開啟。每次按「開始練習」都重新抽題，不會永遠出同一批** |
| 即時回饋 | 練習模式點選即判定，並顯示正確答案與解析 |
| 選項隨機排序 | 預設開啟，避免靠固定位置猜答案 |
| 抽題優先序 | 依「未練過 → 錯題 → 已答對」分層抽取，刷題會逐步覆蓋整個題庫 |
| 學習統計 | 整體正確率、題庫覆蓋率、各分類掌握度、最近 30 次練習記錄 |
| 錯題本 | 集中查看所有錯題與解析，可一鍵重做 |
| 收藏題目 | 練習時可標記星號 |
| 鍵盤操作 | `A`/`B`/`C`/`D` 或 `1`~`4` 選答、`Enter` / `→` 下一題、`←` 上一題 |
| 深色 / 淺色主題 | 右上角切換 |

### 抽題規則

首頁「題目數量」下方有兩個開關：

- **每次重新抽題**（預設開啟）
  - 開啟：每次按「開始練習」都重新抽題；題池大於所需題數時，會**優先抽尚未練過的題目**，其次是有錯過的題目，最後才是已答對的。這樣反覆練習會逐步覆蓋整個題庫，而不是一直重複同一批。
  - 關閉：回到嚴格順序 —— 順序練習固定從題號最小的開始出題，每次結果相同。
- **選項隨機排序**（預設開啟）：每題顯示時重洗選項順序，避免靠固定位置猜答案。

### 管理員

管理員入口**預設隱藏**，學生不會看到「管理員」按鈕。開啟方式有兩種：

| 方式 | 操作 |
|---|---|
| 連點頁腳 | 點頁腳的版本號 **`v1.0`** 連續 **5 下**（1.8 秒內） |
| 網址 | 在網址最後加上 **`#admin`**，例如 `index.html#admin` |

登入後導覽列才會出現「管理員」按鈕，登出後再次隱藏。

> 首次使用預設密碼 `admin123`，登入頁會顯示提示；**一旦修改密碼，提示就會自動消失**，避免學生從提示得知密碼。

| 功能 | 說明 |
|---|---|
| 登入 | 預設密碼 `admin123`，登入後可修改 |
| 題庫列表 | 依分類篩選、關鍵字搜尋（題目／選項／解析） |
| 新增 / 編輯 / 刪除 | 完整表單編輯，含分類、難度、解析、正確答案 |
| 匯出 JSON | 下載完整題庫備份 |
| 匯入 JSON | 可選擇「附加」或「取代」現有題庫 |
| 批次新增 | 一行一題的純文字格式，適合大量貼上 |
| 還原預設題庫 | 回到內建的 650 題 |
| **帳號管理** | 新增／編輯／刪除帳號、重設密碼、停用啟用 |
| **查看學生進度** | 各帳號已練題數、正確率、錯題數、最後活動時間 |
| **匯出帳號密碼清單** | CSV（含 BOM，Excel 可直接開啟） |

## 批次新增格式

在管理員後台點「批次新增」，每行一題，以 `|` 分隔八個欄位：

```
分類|題目|選項A|選項B|選項C|選項D|答案|解析
```

- **分類**：可填 id（`net`/`hw`/`office`/`python`/`web`/`msc`/`daily`/`crime`/`china`）或中文名稱
- **答案**：填 `A`、`B`、`C` 或 `D`
- **解析**：可留空
- 分類無法辨識的行會被**略過**（不會亂歸類）

範例：

```
net|HTTP 默認使用的埠號是？|21|25|80|443|C|HTTP 預設使用 80 埠。
```

## 開發者：驗證與測試

```bash
# 題庫完整性檢查（id 唯一、答案索引合法、分類覆蓋、答案位置均衡度）
node tools/validate.js

# 介面整合測試（需 jsdom）
node tools/test-ui.js

# 重排選項位置（答案均勻分布於 A/B/C/D），會覆寫 assets/data/*.js
node tools/rebalance.js
node tools/rebalance.js --check   # 只預覽結果，不寫檔

# 重新產生使用者帳號（會覆寫 assets/data/accounts.js）
node tools/gen-accounts.js 10

# 重新從參考資料抽取文字
python tools/extract.py
```

> `rebalance.js` 會依題目 id 做決定性重排，同一題每次結果一致，因此可安全重複執行。執行後題庫會合併為「一分類一檔」。

## 備註

- 管理員密碼與**使用者密碼皆以明文儲存**（`ick.admin` 與 `assets/data/accounts.js`），屬**前端簡易保護**，適用於課室／自學場景，不適合作為公開網站的權限控管。
- 隱藏管理員入口只是**提高門檻、避免學生誤觸**，並非真正的安全機制 —— 任何能看到網頁原始碼的人都能找到入口與預設密碼。
- 使用者登入的用途是**區分各學生的練習進度**，不是防止入侵。若需真正的身分驗證，請改用雲端後端。
- 若需多裝置同步、真實帳號系統，可改用雲端後端（資料庫 + 登入），本專案已把題庫、帳號與邏輯分離，易於移植。
